# -Veyon-
Можно обойти пароль админа с помощью программы Elcomsoft System Recovery

Можно обойти с помощью https://github.com/ntdll0/Veyon-antispy на гитхабе, либо остановить службу Veyon в реестре.

Обойти систему мониторинга Veyon (ранее iTALC) на ученическом компьютере можно несколькими техническими способами, основанными на особенностях работы самой программы и операционной системы.
Ниже приведены основные известные методы обхода контроля:

1. Прерывание процесса Veyon Service

Программа состоит из двух частей: графического интерфейса преподавателя (Veyon Master) и фоновой службы на компьютерах учеников (Veyon Service). Если завершить работу этой службы, трансляция экрана и ограничения прекратятся.
• Через Диспетчер задач: Нажмите комбинацию клавиш Ctrl + Shift + Esc. Если у вас есть права администратора, найдите в списке процессов Veyon Service (veyon-service.exe) и нажмите «Снять задачу».
• Через Командную строку (если заблокирован Диспетчер задач):
	1. Откройте командную строку (Win + R -> введите cmd).
	2. Введите команду для принудительного завершения процесса:
taskkill /f /im veyon-service.exe
• Остановка службы Windows: Откройте окно выполнения (Win + R), введите services.msc. Найдите в списке Veyon Service, нажмите по ней правой кнопкой мыши и выберите «Остановить».

2. Сбой через имитацию завершения работы (Метод «Отмена выключения»)

Ученики часто используют уязвимость Windows, связанную с закрытием фоновых программ при выключении:
1. Нажмите комбинацию Alt + F4 на рабочем столе или выберите «Завершение работы» через меню Пуск.
2. Запустится последовательность закрытия системы, которая принудительно завершит процесс Veyon.
3. В момент, когда Windows начнет закрывать открытые программы и выдаст предупреждение (или до того, как компьютер окончательно выключится), отмените выключение компьютера (нажав «Отмена» или запустив команду shutdown /a в командной строке).
4. Служба Veyon закроется, а сама Windows продолжит работать без контроля со стороны учителя.

3. Отключение сетевого доступа (Блокировка портов)

Veyon общается с компьютером учителя по определенным сетевым портам (по умолчанию это порты 11100 и 11400). Если заблокировать эти порты локально, учитель потеряет доступ к вашему ПК.
• Через Брандмауэр Windows: Откройте настройки Брандмауэра в Панели управления, перейдите в «Дополнительные параметры» и создайте «Правило для исходящих подключений», заблокировав трафик для портов TCP 11100 и 11400.
• Отключение сетевого адаптера: Если вам не нужен интернет для выполнения задания, можно просто временно отключить сетевой кабель или выключить Wi-Fi/сетевую карту в настройках параметров адаптера. Учитель увидит, что компьютер «офлайн».

4. Использование комбинаций клавиш при блокировке

Если учитель заблокировал экран (включил режим демонстрации), некоторые старые версии Veyon или ОС с некорректными настройками позволяют свернуть или обойти это окно:
• Попробуйте нажать Ctrl + Alt + Del — на некоторых конфигурациях это позволяет перехватить управление.
• Попробуйте сочетания клавиш Win + D (свернуть все окна) или Alt + Tab для переключения на другие запущенные программы.

5. Запуск сторонней ОС (Live USB)

Если на школьном компьютере не заблокирован BIOS/UEFI, можно загрузиться с флешки (например, с портативной версией Linux или Windows PE). В этой системе агент Veyon просто не будет установлен, и компьютер будет полностью под вашим контролем.
⚠️ Обратите внимание: В современных версиях Veyon администраторы могут включать функцию «Enforce selected mode» (Принудительный режим для клиентских компьютеров). В таком случае, даже если вы перезагрузите ПК или временно закроете программу, при восстановлении связи сервер автоматически вернет блокировку экрана или демонстрацию. Кроме того, обход ограничений на учебных компьютерах может нарушать правила школы или учебного заведения.
