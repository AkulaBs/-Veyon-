# -Veyon-
Как включить встроенную учётную запись администратора
Есть несколько способов.
Через командную строку
Запустите командную строку от имени администратора.
Введите команду: net user Администратор /active:yes (если у вас англоязычная система или некоторые сборки, используйте Administrator).
Нажмите Enter.

Через PowerShell
Запустите PowerShell с правами администратора.
Выполните команду: Get-LocalUser -Name "Administrator" | Enable-LocalUser.

Через оснастку «Локальные пользователи и группы» (lusrmgr.msc)
Откройте lusrmgr.msc.
В разделе «Пользователи» найдите учётную запись «Администратор».
Снимите флажок «Учётная запись отключена» и сохраните изменения.

Через групповые политики (gpedit.msc)
Откройте gpedit.msc.
Перейдите в раздел «Конфигурация компьютера» → «Конфигурация Windows» → «Параметры безопасности» → «Локальные политики» → «Параметры безопасности».
Найдите политику «Учётные записи: состояние учётной записи „Администратор“» и установите значение «Включено».
Обновите политики командой gpupdate /force.
Возвращение предыдущей конфигурации
Если вы хотите вернуть предыдущую конфигурацию (например, после того, как вы или кто-то другой вносил изменения), то это делается через восстановление системы.
Если изменения вносились недавно, можно использовать точки восстановления системы. Нажмите Win + R, введите rstrui и следуйте инструкциям на экране. Эта утилита позволит откатить систему к более раннему состоянию, вернув, например, сетевые настройки, драйверы и другие параметры к состоянию, которое было до появления ошибок.
Если изменения вносились давно или вы не помните, что именно меняли, можно попробовать восстановить систему до точки восстановления, сделанной до появления проблемы. Для этого нажмите Win + R, введите rstrui, и следуйте инструкциям на экране. Утилита поможет откатить систему к состоянию, сохранённому через rstrui, вернув, например, удалённые файлы или изменения в реестре.
Важный нюанс: для работы rstrui требуются права администратора. Если у вас их нет, используйте среду восстановления (Win + R, введите winreagent, запустите bootrec / rebuildbcd).
Что важно учитывать
Права доступа. Убедитесь, что вы вошли в систему под учётной записью, которая имеет права администратора.
Переименование. Если встроенную учётную запись «Администратор» переименовали, команда net user Администратор может выдать ошибку «Пользователь не найден». Чтобы найти текущее имя, используйте команду wmic useraccount where "SID like 'S-1-5-%-500'" get name или в PowerShell Get-LocalUser | Where-Object {$_.Sid -like "*-500"}.
Безопасность. Встроенная учётная запись администратора имеет пустой пароль и обладает полными правами. Используйте её с осторожностью, особенно если не уверены в источнике компьютера.

Как зайти в CMD без прав админа Часть 1: Способ 1: через поиск на панели задач
Нажмите Win + S.
Введите cmd или «Командная строка».
Кликните по найденному результату обычным левым кликом (не через контекстное меню) запустится обычная, не повышенная командная строка.
Способ 2: через окно «Выполнить»
Win + R.
Введите cmd.
Нажмите Enter (не Ctrl+Shift+Enter это сочетание запускает с повышенными правами).
Способ 3: через меню «Пуск»
Откройте «Пуск».
В списке всех приложений найдите папку «Стандартные Windows».
Разверните её, кликните по «Командная строка».
Способ 4: напрямую через файл в системной папке
Откройте проводник, перейдите к C:\Windows\System32.
Найдите файл cmd.exe.
Дважды кликните для запуска.
Способ 5: через адресную строку проводника
Откройте любую папку в проводнике.
В адресной строке введите cmd и нажмите Enter.
Командная строка откроется, сразу находясь в текущей папке проводника (текущая рабочая директория совпадает с открытой в тот момент папкой) удобно, если нужно выполнять команды именно в конкретной папке, не переходя туда вручную через cd.
Особый случай: команда требует повышенных прав, а вы открыли обычную командную строку
Если после выполнения команды появляется сообщение об отказе в доступе это означает, что конкретная команда требует прав администратора. Закройте текущее окно и откройте новое через любой из способов запуска от администратора (см. ссылку в начале статьи), а не пытайтесь повысить права уже открытого обычного окна штатного способа сделать это без перезапуска не существует.
Часть 2. Как сбросить пароль администратора с правами администратора.
Хотя вы не можете показать пароль администратора с помощью CMD Windows 7, вы можете сбросить его, чтобы получить полный доступ. Сброс пароля администратора с помощью командной строки (CMD) может быть практичным решением. Это возможно, если у вас есть законный доступ к системе и права администратора. Крайне важно убедиться, что у вас есть необходимые полномочия для изменения пароля администратора с помощью CMD. Несанкционированное использование этого метода незаконно и неэтично. Вот подробные шаги этого процесса.

Примечание:
Перед сбросом пароля администратора с помощью командной строки или любого стороннего программного обеспечения всегда создавайте резервные копии важных данных. Ошибки в процессе могут привести к потере файлов или ограничению доступа к системе.

Шаг 1 Откройте CMD, введите чистый пользователь и нажмите Enter. Появится список учетных записей пользователей, включая учетную запись администратора. Укажите учетную запись администратора, для которой вы хотите сбросить пароль.

Шаг 2 Введите команду чистый пользователь (имя пользователя администратора) (новый пароль) и нажмите Enter. Замените (имя пользователя администратора) именем учетной записи администратора и (новый пароль) уникальным паролем, который вы хотите установить, например: сетевой пользователь Admin mynewpassword.

Шаг 3 Вы должны увидеть сообщение, подтверждающее успешное выполнение команды. Перезагрузите компьютер и войдите в систему с новым паролем.

Обойти систему мониторинга Veyon (ранее iTALC) на ученическом компьютере можно несколькими техническими способами, основанными на особенностях работы самой программы и операционной системы.
Ниже приведены основные известные методы обхода контроля:

1. Прерывание процесса Veyon Service

Программа состоит из двух частей: графического интерфейса преподавателя (Veyon Master) и фоновой службы на компьютерах учеников (Veyon Service). Если завершить работу этой службы, трансляция экрана и ограничения прекратятся.
• Через Диспетчер задач: Нажмите комбинацию клавиш Ctrl + Shift + Esc. Если у вас есть права администратора, найдите в списке процессов Veyon Service (veyon-service.exe) и нажмите «Снять задачу».
• Через Командную строку (если заблокирован Диспетчер задач):
	1. Откройте командную строку (Win + R -> введите cmd).
	2. Введите команду для принудительного завершения процесса:
taskkill /f /im veyon-service.exe
• Остановка службы Windows: Откройте окно выполнения (Win + R), введите services.msc. Найдите в списке Veyon Service, нажмите по ней правой кнопкой мыши и выберите «Остановить».

2. Сбой через имитацию завершения работы (Метод «Отмена выключения»)

Ученики часто используют уязвимость Windows, связанную с закрытием фоновых программ при выключении:
1. Нажмите комбинацию Alt + F4 на рабочем столе или выберите «Завершение работы» через меню Пуск.
2. Запустится последовательность закрытия системы, которая принудительно завершит процесс Veyon.
3. В момент, когда Windows начнет закрывать открытые программы и выдаст предупреждение (или до того, как компьютер окончательно выключится), отмените выключение компьютера (нажав «Отмена» или запустив команду shutdown /a в командной строке).
4. Служба Veyon закроется, а сама Windows продолжит работать без контроля со стороны учителя.

3. Отключение сетевого доступа (Блокировка портов)

Veyon общается с компьютером учителя по определенным сетевым портам (по умолчанию это порты 11100 и 11400). Если заблокировать эти порты локально, учитель потеряет доступ к вашему ПК.
• Через Брандмауэр Windows: Откройте настройки Брандмауэра в Панели управления, перейдите в «Дополнительные параметры» и создайте «Правило для исходящих подключений», заблокировав трафик для портов TCP 11100 и 11400.
• Отключение сетевого адаптера: Если вам не нужен интернет для выполнения задания, можно просто временно отключить сетевой кабель или выключить Wi-Fi/сетевую карту в настройках параметров адаптера. Учитель увидит, что компьютер «офлайн».

4. Использование комбинаций клавиш при блокировке

Если учитель заблокировал экран (включил режим демонстрации), некоторые старые версии Veyon или ОС с некорректными настройками позволяют свернуть или обойти это окно:
• Попробуйте нажать Ctrl + Alt + Del — на некоторых конфигурациях это позволяет перехватить управление.
• Попробуйте сочетания клавиш Win + D (свернуть все окна) или Alt + Tab для переключения на другие запущенные программы.

5. Запуск сторонней ОС (Live USB)

Если на школьном компьютере не заблокирован BIOS/UEFI, можно загрузиться с флешки (например, с портативной версией Linux или Windows PE). В этой системе агент Veyon просто не будет установлен, и компьютер будет полностью под вашим контролем.
⚠️ Обратите внимание: В современных версиях Veyon администраторы могут включать функцию «Enforce selected mode» (Принудительный режим для клиентских компьютеров). В таком случае, даже если вы перезагрузите ПК или временно закроете программу, при восстановлении связи сервер автоматически вернет блокировку экрана или демонстрацию. Кроме того, обход ограничений на учебных компьютерах может нарушать правила школы или учебного заведения.
