
Способы обхода (для учеников)

1. Создание виртуального стола (Win + Alt + D)
	• Суть: В версиях Veyon (вплоть до 4.9.7) сочетание клавиш Win + Alt + D создает новый виртуальный рабочий стол Windows, поверх которого окно демонстрации или блокировки Veyon просто не отображается.
	• Действие: Нажмите эту комбинацию во время демонстрации, и вы вернетесь к управлению чистым рабочим столом. Переключаться обратно можно через Win + Tab.
2. Обрыв через меню завершения работы (Метод отмены выключения)
	• Суть: Во время блокировки или трансляции системное сочетание клавиш Ctrl + Alt + Delete продолжает работать (если администратор жестко не заблокировал его через групповые политики Windows).
	• Действие: Нажмите Ctrl + Alt + Delete, выберите иконку питания в правом нижнем углу и нажмите «Завершение работы» или «Перезагрузка». Компьютер начнет закрывать программы и принудительно завершит процесс службы Veyon Service. Как только появится предупреждение о закрытии несохраненных программ или выбор, нажмите «Отмена». Служба Veyon упадет, а сессия Windows останется активной.
3. Смена учетной записи через Спящий режим
	• Суть: На некоторых клавиатурах нажатие физической клавиши Sleep (Сон) отправляет ПК в режим ожидания, сбрасывая полноэкранный захват Veyon. При пробуждении компьютер возвращается на экран блокировки Windows, откуда можно войти заново без активной демонстрации.
4. Экранный жест (для сенсорных мониторов)
	• Суть: На моноблоках или ноутбуках с сенсорным экраном под управлением Windows 10/11 работает боковой свайп.
	• Действие: Сделайте свайп пальцем от левого края экрана вправо. Это вызовет меню представления задач (Task View), где можно кликнуть «Создать рабочий стол» и зайти в браузер в обход блокировщика.
